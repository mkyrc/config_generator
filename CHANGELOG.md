# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog,
and this project follows Semantic Versioning.

## [1.1.0] - 2026-08-21

### Added

- Resizable result area

### Fixed

- Highlighted values in some cases have wrong styles

## [1.0.0] - 2026-08-20

### Added

- Initial single-file web app for Jinja template rendering from Excel/CSV.
- Drag and drop upload for Excel/CSV and Jinja template files.
- Table row selection and per-sheet selector for spreadsheet data.
- Missing-value highlighting with optional checkbox toggle.
- Docker packaging with Nginx static serving on port 8080.
- GitHub Actions CI with Docker build, smoke test, and GHCR publish.
